# 基于STM32的高交互性导热系数测量模拟实验系统

第十一届全国大学生物理实验竞赛（创新）自选题1：实验仪器制作、改进
国家级三等奖、省级二等奖

## 项目简介

针对传统稳态法测量导热系数实验中等待稳态耗时过长（1小时以上）、实验广度不足的问题，设计了一套基于STM32单片机的高交互性模拟实验系统。采用"虚实结合"方式，通过1:1实体操作与预置数据库调用相结合，将稳态等待时间从60分钟缩短至10分钟内。

## 系统架构

- **主控**：STM32F103C8T6
- **交互**：矩阵键盘输入 + OLED实时显示
- **核心机制**："操作指令 → 状态识别 → 数据调用"映射系统
- **状态设计**：三阶段状态切换（样品导热 / 上下铜盘接触传热 / 下铜盘散热）
- **误差模拟**：样品偏移、贴合不紧两种误差模式

## 团队分工

本项目为五人团队协作完成。本人负责**实验全过程的原始数据记录与整理**，参与不同样品、不同温度下的导热系数测量与数据采集，协助完成数据作图与初步分析。程序代码由团队成员3完成。
